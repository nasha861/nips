# NIPS: Nigerian IDP Profiling & Support System

A platform for registering, managing and analyzing data about
Internally Displaced Persons (IDPs) in Nigeria.

## Structure
- `client/`: React frontend
- `server/`: Express API
- `analytics/`: Python ETL and SQL
- `powerbi/`: dashboards and data dictionary
- `docs/`: architecture, requirements, API docs
